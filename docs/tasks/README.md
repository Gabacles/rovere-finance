## Convenção

Cada task tem ID estável, título, descrição, contexto/objetivo, dependências, estado, checkboxes de atividade e aceite, testes necessários, implementação, evidências e próximo passo/limitação. IDs não são reutilizados.

Estados: `pendente`, `em andamento`, `bloqueada`, `concluída`. Checkbox do título só recebe `[x]` quando todos os critérios e validações aplicáveis tiverem evidência. Critério não executado permanece `[ ]`.
